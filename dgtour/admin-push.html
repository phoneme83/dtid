앱 푸시 관리

시안 A~F 앱에 알림을 보냅니다. 대상 시안을 골라 발송하면 해당 시안 앱에만 알림이 표시됩니다. 앱은 접속할 때와 약 15분 주기로 발송 건을 확인합니다.

📤 발송 내용
알림에는 개인정보·주민증 정보를 넣지 않습니다.
비워 두면 시안 메인 화면이 열립니다.
현재보다 뒤로 지정하면 예약 발송이 됩니다(앱이 해당 시각 이후 확인 시 표시).
🔔 알림 미리보기
디지털 관광주민증
제목이 여기에 표시됩니다
내용이 여기에 표시됩니다
📋 발송 목록
발송시각대상제목
🗂 notices.json

      

    

  


  
발송 반영 방법 — 이 화면은 정적 홈페이지라 파일을 직접 저장할 수 없습니다. [notices.json 내려받기]로 받은 파일을 dgtour/notices.json 위치에 덮어써 주세요. 그 순간부터 앱이 새 알림을 받습니다.

  운영 시스템에 올릴 때는 이 화면의 입력·대상·이력 구조를 그대로 두고 저장만 서버 API로 바꾸면 됩니다.


  
실시간 푸시(FCM) 전환 — 현재는 Firebase 없이 동작하도록 앱이 확인하는 방식(접속 시 + 15분 주기)입니다. 즉시 도달이 필요하면 Firebase 프로젝트 개설 → google-services.json 발급 → 앱에 FCM 모듈 추가 → 이 화면의 발송을 FCM 전송으로 교체하면 됩니다. 대상 구분(시안별 토픽)·발송 이력 구조는 그대로 재사용됩니다.
