3. 기존 시안(A~E)과의 차이
  • 시안 A~E는 현재 홈페이지 14개 페이지를 그대로 두고 디자인만 교체한 구조입니다.
  • 시안 F는 컨설팅 제안의 정보구조(IA) 자체를 따릅니다 — 하단 5탭(홈·지도·QR·혜택·마이) + 관리자 웹으로 페이지를 새로 구성했습니다.
  • "대한민국 구석구석 종속형"이 아닌 독립 전용 앱/웹을 전제로, 상단 GNB와 하단 탭바를 자체 보유합니다.
  • 지역 실데이터(52개 지역 방문TIP·축제·사용처, 휴가지원제 16개 지역)는 기존 목업과 동일한 data.js를 공유합니다.
4. 테스트 사이트 전제 · 한계
  • 실제 인증(행정망/PASS/모바일 신분증)·결제·환급은 수행하지 않습니다. 로그인은 기존 목업과 동일한 SNS 테스트 계정입니다.
  • 혜택지도는 외부 지도 API를 호출하지 않는 오프라인 SVG 목업이며, 핀 좌표·거리(km)는 업체명 기반 결정론적 값입니다.
  • 관리자 화면의 KPI·추이·순위 수치는 와이어프레임 표기값과 지역 데이터 기반 모의 수치입니다.
  • 이용 실적·포인트·미션·즐겨찾기·휴가지원제 신청은 브라우저 localStorage(dtidF_*)에 계정별로 저장됩니다.
  • 와이어프레임 5종 외에 혜택안내(benefit.html)·휴가지원제(t50.html)·로그인(index.html)은 하단 탭·지갑 진입점이 F안 안에서 완결되도록 추가 구성한 화면입니다.
  • 주민증 발급 개념은 이 목업에서 사용하지 않습니다. 사용자 정보에는 발급 지역이 아니라 실제로 혜택을 이용한 "방문 지역"만 표시됩니다.
