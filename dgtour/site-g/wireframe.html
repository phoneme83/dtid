시안 G — 대한민국 반값여행 통합플랫폼 (착수보고안)

「대한민국 반값여행 통합플랫폼 구축용역 착수보고」(굳앤트, ’26.10., 32쪽)의 화면 구조를 그대로 구현한 테스트 사이트입니다. 화면 구조·흐름은 착수보고를 따르고, 기존 테스트 홈페이지(시안 A~F)에서 더 고도화돼 있던 기능은 그 수준을 유지했습니다.

실제 인증·결제·알림톡 발송은 하지 않는 목업입니다. 신규 9개 지역(화천·태안·서천·안동·영천·함양·산청·장흥·고성)의 연락처·결제수단·업소, 모든 지역의 회차 일정(오늘 기준 상대 날짜)은 시연용 값입니다. 데이터는 이 브라우저의 localStorage(dtidG_)에만 저장됩니다.

2. 기존 테스트 홈페이지에서 이어받은 고도화 기능

  • 신청 정원·대기열(정원의 130%까지, 자동 접수)·과부하 안내, 지역별 버전 카운터로 동시접속 정합성 확인 — 착수보고의 「예산 소진 시 마감」 위에 얹음
  • 신청 가족 유형의 주민등록등본 세대원 선택(배우자·직계만, 이름 마스킹)
  • 정산 지역화폐 연동이 안 되는 결제·숙박 증빙용 영수증 OCR 판독과 입력값 대조, 법인카드(BIN) 판정, 전 계정 대상 중복 제출 탐지
  • 관리자 승인·반려·보완 요청·일정 변경 재승인, 정산 건별 인정/불인정 전환과 판독값 보정 이력, 환급 승인·지급, 통계·CSV(수식 주입 방지)
  • 관리자 공사 총괄 / 지자체 담당자 페르소나 권한 — 지자체는 자기 지역만, 통합 항목은 잠금

3. 착수보고와 다르게 정한 곳 (확인 필요)

  • 운영기준 정산신청 분류의 5번째 항목은 착수보고에서 판독되지 않아 「여행 일정 최대 7일」(p18 규칙)로 채웠습니다. 「정산 단위」는 착수보고 표기대로 「미표기(확인 필요)」입니다.
  • 옵션 항목 수는 운영기준표(p26)의 11개를 따랐습니다(p21에는 15개로 적혀 있음).
  • 방문 필수 개소는 옵션(1~2개소), 기본값 2개소 이상(p28)입니다.
  • 여행 유형 명칭은 「단체(팀)」로 통일했고, 단체 전원이 청년이면 청년팀(최대 28만원·환급률 70%)으로 봅니다.
  • 회차별 일정은 착수보고 예시 날짜 대신 오늘 기준으로 만들어, 언제 열어도 접수중 4 · 오픈예정 9 · 마감 12가 보이게 했습니다.

4. 시연 순서 (5분)

  1. 디주 로그인에서 「네이버」(김수지, 서울 마포구)로 로그인 → 마이페이지에 시연용 신청 6건이 만들어집니다.
  2. 통합 메인에서 거주지를 「강원특별자치도 강릉시」로 바꿔 [확인] → 평창·영월 등이 빗금(신청 불가)으로 바뀝니다. 오픈예정 지역 [🔔 알림] 신청.
  3. 영광군 지역 홈 → [사전신청하기] → 5단계 신청 → 신청번호 확인.
  4. 관리자에서 그 건을 [심사 시작] → [승인] → 오른쪽 아래 알림톡 미리보기(신청자 화면) 확인.
  5. 지역화폐 앱(모의)에서 여행 날짜로 결제 몇 건 → 마이페이지 데모 날짜를 여행 종료 다음 날로 이동 → [QR 방문 인증] → 정산신청에서 [결제내역 불러오기].
  6. 관리자 정산 심사 → [환급 승인] → [지급 처리] → 마이페이지 「환급 완료」와 PIN → 지역화폐 사용법에서 PIN 등록.
  7. 관리자 [운영 기준 설정]에서 평창군 「방문 필수 개소 수」를 바꾸고 [저장] → 평창 지역 홈·정산신청에 바로 반영.
